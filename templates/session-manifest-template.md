# Session Manifest Template

This template defines the structure for the session manifest generated by the
Lead Auditor to track audit session state.

## Session Information

### Session ID

Unique identifier for the audit session.

### Start Time

Timestamp when the audit session started.

### Target Repository

Path to the target repository.

### Audit Workspace

Path to the audit workspace.

---

## Session State

### Current Phase

Describe the current audit phase.

Allowed phases are: Input Normalization, Discovery, Applicability, Planning,
Execution, Consolidation, and Complete.

### Completed Phases

List completed phases.

### Pending Phases

List pending phases.

## Issues and Blockers

Document any issues or blockers encountered during the audit.

Allowed artifact statuses:

- NOT_STARTED;
- IN_PROGRESS;
- COMPLETED;
- BLOCKED;
- NOT_APPLICABLE.

---

## Session Notes

Document relevant session notes.

Update this manifest at session start and after each completed phase. Record the
normalized repository path, selected or missing audit mode, next user decision,
and any skipped or unresolved scope.
