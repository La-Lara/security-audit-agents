# Executive Report Template

This template defines the structure for the executive report generated by the
Lead Auditor during consolidation.

## Executive Summary

Provide a high-level summary of the audit findings, key risks, and
recommendations.

---

## Project Overview

### Project Type

Describe the project type.

### Architecture Summary

Describe the architecture pattern.

### Technologies

List key technologies.

---

## Audit Scope

### Audit Mode

Describe the audit mode executed.

### Domains Assessed

List assessed domains.

### Domains Not Assessed

List domains not assessed with justification, including non-selected,
`NOT_APPLICABLE`, and unresolved `UNKNOWN` domains.
