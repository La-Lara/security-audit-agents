# Discovery Template

This template defines the structure for the discovery artifact generated by the
Lead Auditor during Phase 1 - Project Discovery.

## Project Summary

Describe the project type, purpose, and high-level characteristics.

Evidence sources:

- repository structure;
- README files;
- package manifests;
- configuration files.

---

## Architecture Summary

Describe the observed architecture pattern.

Examples:

- monolith;
- microservices;
- serverless;
- hybrid.

Evidence sources:

- directory structure;
- configuration files;
- deployment manifests;
- documentation.

---

Allowed applicability values:

- APPLICABLE;
- PARTIALLY_APPLICABLE;
- NOT_APPLICABLE;
- UNKNOWN.

Execution decisions MUST follow these rules:

- APPLICABLE: execute the assigned auditor for the scope;
- PARTIALLY_APPLICABLE: execute only the applicable domains or components;
- NOT_APPLICABLE: skip and record the rationale;
- UNKNOWN: pause for clarification or record `NOT_TESTED`; do not infer scope.
